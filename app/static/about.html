What this is

AT LiveCaption is a local, offline, real-time speech-to-text captioning tool for conferences and live events. It takes an audio feed from a microphone or a sound desk's aux/matrix output, transcribes speech continuously as it's spoken, and shows live captions on three outputs at once:

  • This control page — where an operator picks the audio input and adjusts appearance
  • A clean, full-screen audience accessibility screen for a stage-side display
  • A transparent camera/streaming overlay for OBS, vMix, or similar

How it works

  1. Audio comes in from a Windows recording device you select on the control page.
  2. Speech is recognised locally on this PC by a streaming AI speech-recognition model — no cloud service is involved, and no internet connection is required once it's installed.
  3. Recognised text is sent instantly to every connected caption display over a local WebSocket connection — that's why captions appear on all three pages at once, live.
  4. Only finalised caption lines can optionally be saved to a transcript file on this PC. Interim (still-being-recognised) text and raw audio are never saved anywhere.

Privacy & GDPR

This section describes what the software does. It isn't legal advice, and installing this app doesn't by itself make your event "GDPR compliant" — that depends on how you use it. If you're unsure, check with whoever handles data protection for your organisation.

What AT LiveCaption does:

  • Audio is processed only in memory, in real time. It is never written to disk, in any form, at any point.
  • No audio and no caption text is ever sent to an external server or cloud service. All speech recognition runs locally on this PC.
  • The only internet connection this software ever makes is a one-time download of the speech model during first-time setup — a software download, not a data upload. No conference audio or text is involved in it.
  • Live captions are sent over your local network to whichever devices you point at the audience screen and camera overlay URLs. That's how the product is designed to work — keep that traffic on a network you trust.
  • Saving a transcript (finalised captions only — never partial text, never audio) is off by default and has to be explicitly turned on by the operator, on the control page.
  • When enabled, transcripts are stored only in a local folder on this PC (-) and are never transmitted anywhere.

What you're responsible for, as the operator:

  • If your event captions someone else's speech, that recognised text can be personal data under GDPR. You (or your organisation) are the data controller for that processing — this software is just a tool.
  • Consider telling speakers/attendees that live captioning is in use.
  • If you turn transcript saving on, have a plan for how long you keep those files and how you'll delete them when they're no longer needed.
  • Secure the PC and local network this runs on, the same as you would for any other AV equipment handling live audio.
